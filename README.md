# asp-net-framework-modernize-demo
Ett repo med exempelkod för att modernisera från .net Framework v4 till .net10

## Exempel kod
Ett kod exempel som man kan använda sig av för att modernisera sin kodbas från .net Framework v4 till .net10, finns att hämta från:
- [GitHub - AspNetDocs - MvcMovie Sample](https://github.com/dotnet/AspNetDocs/tree/main/aspnet/mvc/overview/getting-started/introduction/sample/MvcMovie/MvcMovie)
- [GitHub - Dotnet Modernization for Beginners - Shared Legacy App](https://github.com/microsoft/dotnet-modernization-for-beginners/tree/main/shared-legacy-app)

Dessa två exempel är en bra startpunkt för att förstå hur man kan modernisera sin kodbas. Det första exemplet visar en enkel MVC-applikation, medan det andra ger en mer omfattande översikt över moderniseringsprocessen (samt innehåller en guilde för hur man kan gå tillväga).
